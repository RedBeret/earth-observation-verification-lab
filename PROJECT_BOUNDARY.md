# Project Boundary

## Purpose

This independently developed civilian lab demonstrates systems integration, formal
verification, geospatial processing, fault recovery, and evidence production.

## Fictional scenario

- Organization: Northstar Environmental Lab
- Platform: TerraWatch
- Exercise: Pine Valley Wildfire Exercise
- Environment: `demo-west`
- Inputs: generated raster scenes, generated weather observations, and generated field
  sensor events

All names, records, positions, times, identifiers, and system behavior are synthetic.
Coordinate values are deliberately fictional test values and are not assertions about
real-world activity.

## Excluded material

The repository must not contain employer or customer identities, real program or unit
details, controlled markings, intelligence collection terminology, real operational
coordinates, real credentials, internal domains, production IP addresses, workplace
schemas, or claims that this reproduces an actual operational system.

## Approved vocabulary

Use Earth-observation data, geospatial processing, environmental event, synthetic
telemetry, area of interest, situation dashboard, analysis result, data source,
end-to-end workflow, and verification evidence.

## Enforcement

Repository validation checks credential shapes, non-local network references, public
binds, suspicious internal-domain patterns, private keys, real email addresses, and
unapproved terms. A private, ignored supplemental term list may be used locally without
publishing sensitive organization-specific terms.
