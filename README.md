# Earth Observation Verification Lab

> This is an independently developed personal project using only synthetic and publicly available information. It does not reproduce an employer, customer, government, military, or production architecture.

`earth-observation-verification-lab` is a systems integration and verification portfolio
project for a fictional civilian environmental-response platform named TerraWatch. It
uses deterministic synthetic Earth-observation scenes, weather observations, and field
sensor events for the Pine Valley Wildfire Exercise in the fictional `demo-west`
environment.

The implementation is being built and verified in the stages recorded in
[IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) and [WORKLOG.md](WORKLOG.md). Full
operator instructions and architecture documentation are added with the verified
services.

## Public-safe boundary

- No real credentials, operational coordinates, internal domains, or production
  addresses are used.
- Test inputs are generated by repository scripts with a fixed seed.
- Optional public imagery may be discussed, but it is never required by tests or CI.
- Generated evidence is redacted before it is written.

## Entrypoint

All local and CI workflows use:

```bash
./scripts/terra.sh <command>
```

Jenkins, GitHub Actions, and GitLab call the same entrypoints in the same order, so a
green pipeline and a green local run mean the same thing.
